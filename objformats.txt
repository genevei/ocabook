distinction between pattern and object formats:
pattern formats - made to store any configuration of cells;
object formats - made to store any identifiable object.

SOF (o): objects are written as runs of cells alternating between each state for each row. "-" and "." characters separate each encoded row of the pattern and conclude the SOF encoding itself, respectively. If the row does not start with an ON cell, the run of OFF cells is written first; if the  row is empty, it is skipped.
The characters in the ASCII set between ":" and "~" inclusive are used to extend the numeral character set for cell runs greater or equal to 10 cells. If a run is still equal to or longer than 79 cells, the character "]" corresponding to a run of 78 cells is written, followed by a "0" and the number that remains after subtraction of the original run with 78, repeated as necessary.
(Repeated empty lines can be truncated to a "+" character and the total number of repetitions, subject to the same rules above, before a non-empty line or the end of the pattern, but this went unimplemented.)
Comments can be defined after the "." character; comments can start either with "!" on the very next line representing a generic string, or begin with the name of the pattern enclosed in parentheses that may appear before or after any generic comments.

To compute the canonical SOF encoding of an object, or the SOF of its **Standard Form**, all phases of the object and the eight orientations of these phases are compared with one another: the preference for encoding is any phase with a distinct smallest population; if no such phase exists, the composite bounding boxes of each phase and the orientation being considered (the union of the bounding boxes) are used to equalise each phase's bounding box. From left-to-right, top-to-bottom, each phase is checked with padding (on the east and south sides) applied; the first instance where an ON cell is present in one pattern where an OFF cell is present in the other is considered the canonical version. All eight orientations (and phases) are sorted by these rules. The Standard Form of an object, and the phase of the SOF encoding, is the first form of this sorting. If both patterns are iterated through and no inequalities are found, the patterns are considered identical for the purposes of sorting. For spaceships, only one orientation is considered: for an orthogonal spaceship, the object is oriented north; for a diagonal spaceship, it is oriented northwest; for an oblique spaceship, it is oriented north-northwest. For linear growth patterns such as guns and puffers, their products are ignored during canonisation.
